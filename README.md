## About Me

I'm currently a Year 2 Software Engineering student who likes working across the full product lifecycle: problem discovery, UI flow, system architecture, implementation, deployment, and presentation.

My strongest interests are:

- **Mobile development** with Flutter and Dart
- **AI-powered applications** using Gemini, Vertex AI, and multimodal workflows
- **Full-stack web systems** with Vue, Express, MySQL, Firebase, and Node.js
- **Human-centered software** for safety, financial inclusion, sustainability, education, and public impact

I also like projects where the code has a real story: campus safety, disaster response, fraud protection, micro-hawker finance, and smart agriculture.
